<h2 align="center">Веб-интерфейс RuFA Hub</h>

### Обзор
**Веб-интерфейс RuFA Hub** предназначен для управления устройствами, подключёнными к системе. 🖥️ С помощью веб-интерфейса пользователи могут добавлять новые устройства, просматривать подключённые устройства и удалять их. Все устройства подключаются к системе только после того, как они отправят сообщение с типом **"I Here"** и содержат уникальный **API-ключ**, полученный через веб-интерфейс. 🔑

## Основные возможности
- Получение API-ключа для устройства: Каждый новый RuFA Connect получает уникальный API-ключ через веб-интерфейс. 🔑
- Подключение устройства: Устройство подключается к RuFA Hub только после отправки сообщения с типом "I Here" и правильным API-ключом. 📡
- Просмотр подключенных устройств: Отображение списка всех подключённых устройств с их IP-адресами и портами. 🌐
- Удаление устройств: Возможность удаления устройств из системы. 🗑️
- Реальные обновления информации: Все изменения отображаются в реальном времени, без необходимости перезагрузки страницы. 🔄
- Интуитивно понятный интерфейс: Простой и удобный интерфейс для работы с устройствами. 💡
## Технические детали
- Backend: Веб-интерфейс использует Flask для обработки запросов, управления данными устройств и обработки сообщений от устройств. 🖥️
- UDP: Для передачи данных между RuFA Hub и RuFA Connect используется протокол UDP, что позволяет эффективно обмениваться информацией между устройствами в реальном времени. 📡
- База данных: Все устройства и их статусы хранятся в базе данных SQLite. 📊
Подключение устройства: Устройство подключается к системе только после отправки сообщения с типом "I Here" и API-ключом, который генерируется в веб-интерфейсе. 🔑💬
