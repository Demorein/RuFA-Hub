<h2 align="center">RuFA Hub</h2>



**RuFA Hub** — это современное Open Source решение для эффективного взаимодействия микроконтроллеров и серверов на аппаратном уровне. Система предоставляет гибкие возможности для разработки и управления устройствами, работая на операционной системе Debian, что обеспечивает стабильность и совместимость с множеством программных пакетов.

<h2 align="center">⚙️ Основные особенности</h2>

- **Удалённое управление**: С RuFA Hub можно удалённо собирать данные с датчиков, подключённых к Arduino с Wi-Fi модулем, и управлять микроконтроллерами через удобный веб-интерфейс.
- **Преобразование обычных устройств в «умные»**: Например, подключив Arduino с температурным датчиком к чайнику, вы можете управлять его температурой через RuFA Hub.
- **Открытый исходный код**: RuFA Hub предоставляет пользователю полный контроль над системой, что позволяет адаптировать её под любые нужды и задачи.

<h2 align="center">🔓 Открытый исходный код и кастомизация</h2>

**RuFA Hub** — это **Open Source** проект, что даёт пользователям полный контроль над системой. Если вам хочется добавить свою уникальную функциональность, например, анимацию заполнения чайника водой или кастомные графики для отображения данных, вы можете вручную отредактировать веб-сервер RuFA Hub и интегрировать всё, что вам нужно.

Благодаря гибкости кода, вы можете:
- Изменять веб-интерфейс, добавляя анимации, кастомные панели и виджеты.
- Интегрировать новые API или датчики, расширяя возможности системы.
- Улучшать визуализацию данных, создавая графики и анимации в реальном времени.

Всё ограничивается только вашей фантазией и потребностями!  

<h2 align="center">📊 База данных</h2>

**RuFA Hub** использует базу данных **SQLite**, которая может располагаться не только на физическом носителе, но и на NAS или в облачных хранилищах, таких как **NextCloud** или **Google Drive**. Это даёт дополнительную гибкость в выборе места хранения данных и упрощает доступ к ним.

<h2 align="center">🔌 Рабочий процесс с микроконтроллерами и RuFA Hub</h2>

### Перепрошивка микроконтроллера

Перепрошивка микроконтроллеров через локальную сеть (Wi-Fi или LAN) осуществляется с помощью модуля **RuFA Connect**. Этот модуль оснащён Wi-Fi модулем и LAN коннектором, что позволяет легко обновлять прошивки микроконтроллеров на расстоянии, без необходимости физического подключения.

### Отправка данных на RuFA Hub

Для того чтобы данные с микроконтроллера отправлялись на **RuFA Hub**, необходимо установить специальный модуль для **Arduino IDE** под названием **MCIS IDE**. Этот модуль позволит вам отправлять данные, например, с Arduino на RuFA Hub.

### Получение API Key и отправка данных

Чтобы данные, отправленные через **RuFA Connect**, корректно принимались и обрабатывались на **RuFA Hub**, вам нужно будет получить **API Key** в веб-интерфейсе RuFA Hub, который доступен по локальному IP-адресу устройства.

В пакете данных, который отправляется на **RuFA Connect**, должен быть обязательный ключ с названием `APIKey`. Пример пакета данных:

```json
{
  "Fan1": "172 rps",
  "Fan2": "82 rps",
  "APIKey": "your-api-key"
}
```
Важное замечание
Если пакет будет отправлен без ключа APIKey, RuFA Hub проигнорирует его. Это сделано для обеспечения безопасности системы, чтобы избежать попыток несанкционированного доступа и защиты от злоумышленников.

## Получение данных с RuFA Connect

**RuFA Hub** собирает все пакеты, отправленные с **RuFA Connect**, в один большой пакет данных перед их обработкой. Это позволяет оптимизировать хранение, снизить нагрузку на систему и обеспечить удобную структуру для дальнейшей работы с данными.  

Формирование пакета данных

После получения информации от **RuFA Connect**, **RuFA Hub** формирует общий пакет данных в следующем формате:

```json
{
    "Conncet_1": {
        "data1": "data1",
        "data2": "data1",
        "data3": "data1",
        "APIKey": "Key"
    },

    "Conncet_2": {
        "datapack": {
            "data4": "data1",
            "data5": "data1",
            "data6": "data1",
        },
        "APIKey": "Key"
    }
}
```

Описание структуры данных

- "APIKey": "Key" — API-ключ, необходимый для аутентификации пакетов. Без него RuFA Hub проигнорирует входящие данные.

- "data1", "data2", "data3" — данные, которые поступили с первого RuFA Connect (Conncet_1).

- "data4", "data5", "data6" — данные, которые поступили со второго RuFA Connect (Conncet_2).

- "datapack" — это данные, которые пришли со второго RuFA Connect в виде уже готового пакета данных.

Частота сбора данных

По умолчанию RuFA Hub формирует общий пакет данных каждые 2 секунды. Этот интервал можно изменить в веб-интерфейсе RuFA Hub в зависимости от требований пользователя.

Обработка задержек

Если какие-либо устройства не успели отправить данные в течение 2 секунд, они будут включены уже в следующий пакет данных. Это гарантирует, что вся информация будет обработана и сохранена без потерь.
Пока данные не записаны в пакет, они хранятся в ОЗУ RuFA Hub.


<h2 align="center">🔧 MCIS (Microcontrollers Control and Interaction System)</h2>
MCIS — это система, разработанная RuFA Team, которая объединяет множество микроконтроллеров в одну компактную систему — RuFA HUB. Она служит для дистанционной прошивки микроконтроллеров и позволяет отправлять данные между микроконтроллерами и сервером через TCP-соединение по Wi-Fi или LAN.

-------------------------

Основные функции MCIS:

- Соединение микроконтроллеров: объединяет несколько микроконтроллеров в одном месте для управления и мониторинга.
- Дистанционная прошивка: позволяет обновлять прошивки микроконтроллеров удалённо, используя Wi-Fi или LAN.
- Безопасная передача данных: отправка пакетов данных по TCP-протоколу, обеспечивающему надёжную и стабильную связь.
- С помощью MCIS вы можете легко управлять множеством микроконтроллеров, получать данные и обновлять их прошивки, не выходя из системы RuFA HUB.




<h2 align="center">🛠️ Решение проблем (FAQ)</h2>


Если возникли ошибки или данные не отображаются в **RuFA Hub**, вы можете проверить логи устройства.

📜 Просмотр логов

1. **Через веб-интерфейс**  
   - Откройте **WEB-интерфейс RuFA Hub**.  
   - Перейдите в раздел **Система → Логи**.  
   - Ознакомьтесь с сообщениями об ошибках.  

2. **Напрямую на сервере (Debian)**  
   Если веб-интерфейс недоступен, логи можно найти в корневой папке **RuFA Hub**:  

   ```bash
   cd /path/to/RuFA-Hub/logs
   cat error.log

Здесь содержатся ошибки сервера, сетевые проблемы и другие важные сообщения.

❓ Частые проблемы и их решения
Сервер не запускается
→ Убедитесь, что установлены Python 3 и все зависимости.
```bash
sudo apt update && sudo apt install python3 python3-pip sqlite3
```
Микроконтроллер не отправляет данные
→ Проверьте API Key, Wi-Fi соединение и корректность запроса.
Данные не отображаются в веб-интерфейсе
→ Проверьте соединение с базой данных SQLite и перезапустите сервер:
bash
```
systemctl restart rufa-hub
```
